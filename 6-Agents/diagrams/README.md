# Agent Diagrams

Auto-generated graph plots for the runnable examples in [`6-Agents/`](../README.md).

Like the [workflow diagrams](../../5-Workflows/diagrams/README.md), these images
are generated when the source scripts run—they are build artifacts, not
hand-drawn illustrations. The older example uses the shared
[`plot_graph()`](../../util.py) helper; the two new examples render their
compiled graphs locally and continue running if PNG rendering is unavailable.
The [tutorial README](../README.md) includes a sequence diagram showing the loop
executing over time.

Details that are easy to trip on:

- **The name and the source number don't match.** The file is `00_...`, but it's generated by `01_tool_calling_agent.py` (that script hard-codes the `diagrams/00_...png` output path). The *simple* example, [`00_tool_calling_agent_simple.py`](../00_tool_calling_agent_simple.py), calls `plot_graph()` with no path, so it writes `graph.png` into the working directory (git-ignored) rather than here.
- **One diagram covers both examples.** The simple and full agents compile to the *same* two-node shape — `llm ⇄ tools` with a conditional exit to `END`. So even though only one PNG is committed, it faithfully represents the structure of both scripts. What differs between them is the tool node's *implementation* (hand-written vs. prebuilt `ToolNode`), not the graph's wiring.
- **The new examples expose the alternatives.** The Command version has the
  same runtime topology but declares routing inside the model node. The
  prebuilt version shows the equivalent graph generated by `create_agent`.
