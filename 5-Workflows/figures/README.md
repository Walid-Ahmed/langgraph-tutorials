# Workflow Figures

Concept illustrations embedded in the [workflow tutorial](../README.md) to picture each pattern before the code appears.

Unlike the [`diagrams/`](../diagrams/README.md) folder — which holds plots auto-generated from *this repo's* graphs — these are **teaching figures** that illustrate the patterns in the abstract. The slides (`workflow-00` to `workflow-06`) are fixed reference art; `workflow-07` to `workflow-11` are generated by a script.

**Sources:** `workflow-00` to `workflow-06` are slides adapted from the workflow-types deck below. `workflow-07` to `workflow-11` are original figures drawn for this repo in the book's house style by [`make_workflow_figures.py`](make_workflow_figures.py); edit that script and re-run it to change them:

```bash
python "5-Workflows/figures/make_workflow_figures.py"
```

Source of the slides: [Workflow types deck](https://docs.google.com/presentation/d/1SuUtO_OCcglql3DRU5KnbKtxxHokxPhX/edit?slide=id.p2#slide=id.p2)
